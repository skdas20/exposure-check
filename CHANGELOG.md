# Changelog

## 0.1.0 (2026-10-25)

First release.

- 40 content-verified checks for `.env` files, VCS metadata, private keys, credentials, database dumps, backups and information leaks.
- SPA catch-all detection via a random-path baseline.
- CLI with `--fail-on`, `--json`, `--header`, `--timeout`, `--concurrency` and `--list`.
- GitHub Action with job summary output.
